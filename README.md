# sqlserver
npm install express pg dotenv cors sequelize -D nodemon - модули
npm init -y - запустить сервер
Dotenv - секретные данные в окружении в защите
express- маршрутизация сервера запуск через api endpoint
cors - позволяет подключаться к серверу с других компьютеров
sequelize - позволяет работать с бд через javascript работает вместе с pg
pg - ядро постгресс без него не будет работать сервер
nodemon - перезапуск сервера при изменениях сервера
Прежде чем проектировать бд необходимо сделать диаграмму
router.use метод промежуточного для настройки серверов
aliexpress.json - посредник разбирающий входные данные
req.body
responce.body
